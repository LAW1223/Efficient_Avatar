Efficient by design.

Two complementary techniques make the model cheaper to run.

  1. Original modelFull-size avatar generator
  2. DistillationLearn a more efficient model
  3. Distilled modelLess computation per video
  4. QuantizationLower numerical precision
  5. Efficient inferenceLighter on available hardware

Distillation

A more efficient model is trained to reproduce the behaviour of the original one, so it needs less computation to generate each video.

Quantization

Model weights are stored and computed at lower numerical precision. This reduces memory use and makes inference lighter on the hardware that is available.
